# Встроенные шрифты рендера

Все четыре — под SIL Open Font License 1.1 (тексты лицензий лежат рядом в `LICENSE-*.txt`), с кириллицей,
вариативные по насыщенности. Подмножества `latin` и `cyrillic` в woff2, загружаются через `FontFace`
(`src/render/fonts.ts`) и в окне, и в воркере.

| Семейство в движке | Шрифт     | Роль                              | Насыщенность | Источник                               |
| ------------------ | --------- | --------------------------------- | ------------ | -------------------------------------- |
| `STV Inter`        | Inter     | гротеск, основной текст и лирика  | 100–900      | `@fontsource-variable/inter@5.3.0`     |
| `STV Unbounded`    | Unbounded | акцидентный/дисплейный, заголовки | 200–900      | `@fontsource-variable/unbounded@5.3.0` |
| `STV Oswald`       | Oswald    | узкий, запасной для длинных строк | 200–700      | `@fontsource-variable/oswald@5.3.0`    |

Файлы взяты из npm-пакетов Fontsource (через jsDelivr, `files/<font>-<subset>-wght-normal.woff2`
и `LICENSE`), без изменений, кроме имени файла. Префикс `STV` в имени семейства нужен, чтобы
установленный в системе одноимённый шрифт не подменил встроенный: иначе экспорт на разных машинах
выглядел бы по-разному.
