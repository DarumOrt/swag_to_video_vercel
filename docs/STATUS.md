# Состояние проекта

Обновляет главная сессия на границе каждой вехи. Детали по модулям — в `docs/reports/<модуль>.md`.

## Решения (кроме ключевых из `CLAUDE.md`)

- Основной путь текста: Whisper small в браузере → выравнивание по вставленному тексту (`alignLyrics`) →
  магнит к вокальным онсетам → редактор. CTC-выравниватель (MMS) — проба позже, не основной путь.
- Модели: лёгкая конфигурация по умолчанию (WebGPU fp16+q4f16, иначе WASM q8); turbo — только «Максимум»,
  грузится с `onnx-community` (зеркала нет). HTDemucs и выравниватель на HF ещё не залиты.
- Рендер: Canvas 2D-слои + цепочка WebGL2 пост-проходов от эффектов (`effectsHost`). Детерминизм: кадр N
  зависит только от данных и номера кадра; превью = экспорт.
- Экспорт: WebCodecs + mediabunny, в воркере; длинные/4K — запись потоком (файл или OPFS).
- Шрифты встроены (OFL): Inter, Unbounded, Oswald, с кириллицей.
- Акценты: авто-подсказки (`suggestAccents`, `source: 'auto'`) + ручная правка (`'user'`).
