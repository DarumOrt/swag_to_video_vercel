# Фронтенд и UI — итоговый отчёт

## Структура `src/app`

- **Store:** `store.ts` — трек, статус анализа, `timeline`, `output`, экспорт (прогресс, ETA), `style {presetId, values}` и `scene`, собранная из стиля. Один объект `scene` уходит в превью и в экспорт. `lyricsStore.ts` — состояние редактора: распознавание, окно загрузки модели, тап-синк, выбранное слово.
- **Плейхед:** `playback.ts` (`<audio>` + rAF) обновляет DOM и канвас напрямую, мимо React. Элемент создаётся лениво, чтобы модуль импортировался в Node.
- **Экшены:** `actions.ts` (трек, экспорт), `lyricsActions.ts` (распознавание, вставка, выравнивание, LRC, тап-синк), `accentActions.ts` (акценты через `@/lyrics`, предпросмотр акцента). Чистые правки текста — в `lyricsEdit.ts`.
- **Адаптеры (`adapters/`, единственная точка входа к модулям):**
  - `analysis.ts`: `@/audio`; PCM хранится в WeakMap по таймлайну, поэтому новый `Timeline` создавать только через `patchTimeline`/`withLyrics`.
  - `transcribe.ts`: `@/ml`; `modelStatuses()` (оценка по обоим качествам), `modelCacheInfo()`, `clearModelCache()` (=`deleteCachedModels`, чистит все модели). В dev `?fake-asr` включает фейк (`transcribe.fake.ts`) с in-memory «кэшем»: light загружен, max нет.
  - `exporter.ts`: экспорт в воркере, фолбэк в основной поток, выбор места сохранения.
  - `params.ts`: схема параметров для автоматических форм.
- **Компоненты:** `Preview`, `Transport`, `Sidebar` (вкладки Стиль / Акценты / Формат), `StylePanel`, `ParamControls`, `ExportPanel`, `lyrics/*` (`LyricsPanel`, `WordList`, `WordEditor`, `PasteForm`, `TapBar`, `RecognizePrompt`), `accents/*`. Примитивы дизайн-системы — в `src/ui`, токены — в `src/index.css`.

## Готово

Загрузка трека, превью с переключением формата на лету, плеер, экспорт (воркер, OPFS или файл, ETA, отмена). Редактор текста:

- распознавание: окно настроек открывается **всегда** (и при закэшированной модели), показывает статус каждого качества («Уже загружено в кэш · N МБ» / «Скачать N МБ»), «Очистить кэш моделей · N МБ» с подтверждением (недоступно во время распознавания), после очистки статусы обновляются. Когда текст уже распознан — кнопка «Распознать заново»; если есть правки слов (`edited`) или вставленный/LRC-текст, первое нажатие просит подтверждение (текст пользователя остаётся и перепривязывается, распознанный с правками — заменяется);
- вставка текста с привязкой к распознанному и счётчиком привязанных слов;
- тап-синк с магнитом;
- правка слов, импорт и экспорт LRC.

Вкладка «Стиль»: 5 пресетов (в т.ч. «Полноэкранный текст») с миниатюрами и автоформой; блок «Режиссёр» (если у сцены есть `director`): «Перемешать» (`style.seed` → `scene.seed`), ручки энергия/хаос/случайность (энергия/хаос скрыты, если уже есть в схеме пресета; значения в `style.director`, накладываются в `buildScene`). Превью и миниатюры пересоздают рендерер через `useThrottled` (160 мс).

Акценты (веха 4): у слова любой список акцентов (`WordAccentPicker` + `AccentEditor`: эффект, сила, длительность/спад, параметры схемы вкл. `breathe`, «до слова…» → клик по слову в списке (`rangePick` в `lyricsStore`, `pickRangeEnd`; слова раньше начала подсвечены красным и не принимаются), снятие диапазона). В списке слов: цветная полоска под диапазоном (`EFFECT_COLORS`), бейдж числа акцентов. Вкладка «Акценты» — группы «Удары»/«Режимы» (`effectGroup`), 15 иконок. Экшены по id: `addWordAccent/updateAccent/removeAccent/setAccentEnd/applyAccentToSameWords`.

Сетка BPM (`GridControls`, `lyricsActions.setGrid`): после выравнивания `beatGridFit` → авто-вкл при `score ≥ GRID_AUTO_THRESHOLD`, деление из `suggestedDivision`; снап всегда от `grid.base` (выровненные слова). Ручные правки/тап/вставка сбрасывают `base` (снап «запекается», выключением не откатить). Показ «ровность бита: N%».

## Адаптеры к модулям (заглушек больше нет)

- `adapters/style.ts`: `STYLE_PRESETS` из `@/render` (RU-подписи), `build` добавляет `effects: styleEffects(effectStyle)` из `@/effects`, поэтому в превью и экспорте видны бит-камера и пост-проходы.
- `adapters/effects.ts`: 15 акцентов из `ACCENT_EFFECT_ORDER` / `ACCENT_EFFECTS` (`@/effects`) с описанием и параметрами.
- `adapters/convert.ts`: `ParamSpec` (`number|boolean|enum|color|text`) → `ParamSchema` (`range|toggle|select|color|text`), берутся только RU-подписи.
- `DEFAULT_PRESET_ID` = `DEFAULT_STYLE_PRESET` ('neon'). EN-подписи пока не используются: `ParamSchema` хранит одну строку.

## Известные проблемы и ловушки

- `pickSaveTarget` должен быть первым `await` в обработчике клика: диалогу сохранения нужен жест пользователя.
- Троттлинг пересоздания рендерера сделан (`useThrottled`); в браузере на настоящем слайдере не мерили.
- Веха 4 в браузере проверена скриптом на синтетическом треке + `?fake-asr` (два акцента на слово, диапазон, сетка, перемешать — без ошибок консоли); визуально эффекты режимов не смотрели. Не проверены: экспорт после перехода на воркер, вкладка «Акценты» на настоящем `@/lyrics`, реальный Whisper, узкие экраны, импорт LRC.

- Статус кэша по качеству берётся из `estimateModelDownload` (`totalBytes − toDownloadBytes`); отдельной правки `@/ml` не нужно. Размер «освободится» = `max(listCachedModels bytes, загруженное по оценке)`: `bytes` считается по `content-length`, он может быть 0 — тогда работает запасной вариант. Чистятся все модели HF, не только Whisper.
- Окно и очистка проверены только юнит-тестами (`lyricsActions.test.ts`, мок адаптеров); в браузере не смотрели.
