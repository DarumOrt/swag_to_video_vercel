# Сессия: Рендер-движок и визуализация

**Владеет:** `src/render/`, `src/visualizers/` (эффекты и пост-обработка — у сессии «Эффекты», `docs/sessions/effects.md`;
рендер-движок даёт им точки расширения: камера, оверлей, цепочка пост-проходов)

## Зона ответственности

Собственный детерминированный рендер-движок и всё, что видно в кадре: визуализаторы, текст, эффекты акцентов.
Без Remotion. Один и тот же код рисует превью в реальном времени и кадры для экспорта.

## Что должно получиться

- **Движок слоёв:** сцена = стек слоёв (фон, визуализатор, текст, эффекты, пост-обработка).
  Каждый слой — `draw(ctx, frame)`, где `frame` = номер кадра, время, аудио-признаки кадра, активные слова/акценты.
  Никакого `Date.now()`/случайности без сида — только от номера кадра.
- **Разрешение-независимость:** вёрстка в относительных единицах; 9:16, 16:9, 1:1, 4:5, произвольный размер,
  безопасные зоны под интерфейс TikTok/Reels.
- **Визуализаторы в духе MiniMeters:** спектр (бары/линия/«горы»), спектрограмма-водопад, осциллограф,
  waveform, гониометр/вектороскоп, корреляционный метр, LUFS/RMS/пик-метры.
- **Реакция на ритм:** пульсация, камера, вспышки, частицы, глитч.
- **Кинетическая типографика:** появление слов/строк, караоке-заливка, стили (RU/EN шрифты, кириллица!).
- **Эффекты акцентов на словах:** zoom-удар, глитч, смена палитры, взрыв частиц, слово на весь экран,
  замедление, инверсия — с параметрами и окном ±N кадров.
- **Пресеты** = сохранённые наборы слоёв и параметров.
- Опционально: слой Butterchurn (Milkdrop, MIT) — проверить лицензию пакета пресетов.

## Требования

- WebGL2 / Three.js + GLSL, Canvas 2D для текста; работа через OffscreenCanvas в воркере, где возможно.
- 60 fps превью 1080×1920 на среднем ноутбуке без дискретной видеокарты.
- Предоставить экспорту API «отрисуй кадр N в канвас W×H».

## Связи

- **Аудио-анализ** — покадровые признаки. **Лирика** — слова и акценты.
- **Фронт** — превью-канвас, панели параметров. **Экспорт** — покадровый вызов движка.
