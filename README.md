# SwagToVideo

Браузерное приложение, которое превращает трек и текст песни в видео-визуализацию:
измерители в духе MiniMeters, кинетическая типографика и эффекты-акценты на выбранных словах.
По умолчанию — вертикальное 9:16 для соцсетей, формат, разрешение и fps настраиваются.

> Статус: проектирование. Кода приложения пока нет.

## Принципы

- **Всё работает на устройстве пользователя.** Трек и текст никуда не загружаются, сервера нет.
- **Без внешних API.** Нейросети (Whisper для текста, HTDemucs для вокала) запускаются прямо в браузере
  через WebGPU/WASM. Веса скачиваются один раз и кэшируются.
- **Свой рендер-движок** и экспорт видео через WebCodecs.

## Стек

Vite · React · TypeScript · Tailwind · shadcn/ui · Zustand · Web Audio API · WebGL2 / Three.js ·
WebCodecs · mediabunny · transformers.js · onnxruntime-web

Рекомендуемый браузер: Chrome или Edge последних версий.
